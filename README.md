# QuickNotes

QuickNotes is a simple note-taking web app that allows users to create, organize, search, and delete notes by category. Notes are saved in the browser using localStorage so they remain available after refreshing the page.

## Features

- Add notes with Personal, Work, or Study categories
- Validate empty notes and notes longer than 200 characters
- Display notes with category and date/time
- Delete individual notes
- Search notes as you type
- Display the current note count
- Save notes using localStorage
- Responsive layout for smaller screens

## How to run locally

1. Clone or download the repository.
2. Open the `quicknotes-app` folder in VS Code.
3. Open `index.html` using Live Server.
4. Use the form to add and manage your notes.
